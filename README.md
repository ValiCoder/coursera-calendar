# Учебный календарь Coursera

Календарь курсов второго триместра. Работает в браузере на Windows и macOS без установки, автозапуска и изменения системных файлов.

У каждого посетителя чистый индивидуальный план: 0 пройденных модулей, пустой прогресс, отключённые напоминания. Данные сохраняются в хранилище этого сайта в браузере. Другой браузер или профиль создаёт новый план. Очистка данных сайта удаляет сохранённый прогресс; можно скачать его копию.

Возможности: календарь и список модулей, четыре параллельных предмета, последовательное прохождение, ручной процент прогресса, общая или отдельная дата начала, перенос будущих модулей с сохранением фактических завершений, ссылки на Coursera. Для обычного предпринимательства пока показано ожидание списка; технологический план сохраняется при переключении.

Отметка прохождения меняет только статус: плановые даты и длина полос всех модулей сохраняются. Кнопка «Убрать отметку» отменяет прохождение выбранного модуля, не снимая отметки остальных. Даты меняются только через настройки. При обновлении старого профиля сжатые полосы и автоматически сдвинутые даты восстанавливаются из выбранной даты начала; фактические отметки и проценты сохраняются.

Один клик по модулю выбирает его. Двойной клик по строке или полосе календаря и строке списка модулей открывает курс в Coursera в новой вкладке. Поля процента и ссылки сохраняют своё обычное поведение.

Карточки предметов показывают суммарные часы всех модулей и пройденные часы с учётом их процентов прогресса. Завершённый модуль учитывается целиком. Часы отображаются с точностью до одной десятичной цифры; это оценка выполненной части плана, а не таймер занятий.

Напоминания требуют явного разрешения браузера и работают **только при открытом календаре**. Доступны тест, пауза на час и выключение. После закрытия вкладки отправка прекращается. Сервер фоновых push пока не подключён по выбору владельца. Браузер может замедлять таймеры в фоновой вкладке или при сне компьютера.

## Публикация

В Settings → Pages выберите **GitHub Actions**. `.github/workflows/pages.yml` публикует только папку `public/`. Сайт полностью статический; ключей и личного прогресса в репозитории нет.

## Проверка для разработчика

`node tests.mjs` проверяет даты, последовательность, переносы и независимость профилей. `node server.mjs` запускает локальную разработческую версию на localhost:47832. Пользователям эти команды и Node.js не нужны.

Важные даты: окончание подписки — 5 ноября 2026 года, сдача заявлений — 1–9 ноября включительно. Начальные значения можно изменить или убрать в личных настройках. Они показываются в отдельном блоке и строках календаря, не двигают курсы и не меняют прогресс. Полный календарь охватывает эти сроки.
